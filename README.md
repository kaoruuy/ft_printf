# ft_printf

## Description

`printf` の基本的な変換を実装しました。
書式文字列に合わせて標準出力に書き込み、出力したバイト数を返します。
文字列の長さの取得にはlibftの `ft_strlen`、16進数の大文字変換には `ft_toupper` を使っています。
`malloc` は使わず、出力には `write` を使っています。

対応している変換は以下の9種類です。幅・精度・フラグなどのボーナス部分は実装していません。

### 対応している変換

| 指定子 | 引数 | 出力内容 | 例 |
| --- | --- | --- | --- |
| `%c` | `int` | 引数を `char` に変換して1文字出力します。 | `ft_printf("%c", 'A')` → `A` |
| `%s` | `char *` | 文字列を終端の `\0` の手前まで出力します。 | `ft_printf("%s", "hello")` → `hello` |
| `%p` | `void *` | アドレスを `0x` 付きの小文字の16進数で出力します。 | `ft_printf("%p", (void *)&n)` → `0x...`（アドレスは実行時に決まります） |
| `%d` | `int` | 符号付き整数を10進数で出力します。負の値には `-` が付きます。 | `ft_printf("%d", -42)` → `-42` |
| `%i` | `int` | `%d` と同じく、符号付き整数を10進数で出力します。 | `ft_printf("%i", 42)` → `42` |
| `%u` | `unsigned int` | 符号なし整数を10進数で出力します。 | `ft_printf("%u", 42u)` → `42` |
| `%x` | `unsigned int` | 小文字の `a`〜`f` を使って16進数で出力します。`0x` は付きません。 | `ft_printf("%x", 255u)` → `ff` |
| `%X` | `unsigned int` | 大文字の `A`〜`F` を使って16進数で出力します。`0X` は付きません。 | `ft_printf("%X", 255u)` → `FF` |
| `%%` | なし | `%` を1文字出力します。引数は使いません。 | `ft_printf("100%%")` → `100%` |

`%c` の引数を `int` で受け取るのは、可変長引数では `char` が `int` に昇格するためです。
`'\0'` を渡した場合も1バイト出力し、戻り値に数えます。
`%s` は終端の `\0` を出力しないので、空文字列なら出力は0バイトです。

Linux環境を対象としており、`%s` にNULLを渡すと `(null)`、`%p` にNULLを渡すと `(nil)` を出力します。

### 戻り値とエラー

戻り値は、変換した部分と通常の文字を合わせた出力バイト数です。
たとえば `ft_printf("%s: %d", "age", 20)` は `age: 20` を出力し、`7` を返します。

書き込みに失敗した場合や、出力バイト数が `INT_MAX` を超える場合は `-1` を返します。
書式文字列自体がNULLの場合、未対応の指定子がある場合、末尾が `%` だけの場合も `-1` です。
途中でエラーになったときは、それまでに出力した文字はそのまま残ります。

## Instructions

リポジトリのルートで実行します。

```sh
make        # libftをビルドし、libftprintf.a を生成
make clean  # libftを含むオブジェクトファイルを削除
make fclean # libft.a と libftprintf.a も削除
make re     # 再ビルド
```

使うときは `ft_printf.h` をインクルードし、`libftprintf.a` をリンクします。
libftのオブジェクトも含めているので、`libft.a` を別にリンクする必要はありません。
たとえば、ルートに次の `main.c` を置いて実行できます。

```c
#include "ft_printf.h"

int	main(void)
{
	ft_printf("Hello %s: %d, %x, %%\n", "42", -42, 42u);
	return (0);
}
```

```sh
cc -Wall -Wextra -Werror main.c -L. -lftprintf -o example
./example
```

出力は `Hello 42: -42, 2a, %` になります。

## Algorithm and data structures

処理は2つのファイルに分けています。

- `ft_printf.c`: 書式文字列を先頭から読み、通常の文字はそのまま出力します。`%` があれば、次の文字に応じて `va_arg` で引数を取り出し、出力用の関数を呼びます。
- `ft_print.c`: 文字・文字列・数値・ポインタを出力します。各関数は出力したバイト数を返し、失敗した場合は `-1` を呼び出し元に返します。

数値の出力には再帰を使っています。基数で割った商を先に出力し、余りを最後の1桁として出力します。
たとえば10進数の `123` なら、`12` の出力を済ませてから `3` を出力する流れです。
基数を切り替えて、10進数と16進数で同じ関数を使っています。
`%X` では各桁を `ft_toupper` で大文字に変換します。

文字列は `ft_strlen` で長さを求めてから、まとめて `write` に渡します。
一部だけ書き込まれた場合は、残りを続けて出力します。
libftの `ft_putchar_fd` や `ft_putstr_fd`、`ft_putnbr_fd` は書き込みの成否を返さないため、
エラーを検出する必要がある出力処理では直接 `write` を使っています。

負の整数は先に `-` を出力します。絶対値は `unsigned int` の演算で求め、
`INT_MIN` をそのまま符号反転するとオーバーフローする問題を避けています。
ポインタは `unsigned long` に変換し、`0x` の後に16進数で出力します。

引数の読み取りには `va_list` を使い、構造体やグローバル変数は使っていません。
出力をためるバッファもなく、数値の変換では桁数に応じた再帰スタックを使います。
